## 🚀 Advanced Java – JDBC with MySQL

## 📌 Project Overview
This project demonstrates Advanced Java by connecting a Java application to a MySQL database using JDBC (Java Database Connectivity).
It performs database operations such as Create, Read, Update, and Delete (CRUD) using JDBC API.

## 1️⃣ Installation & Setup Guide
## 🔹 Step 1: Install Java (JDK)
1. Download the latest JDK (Java Development Kit).
2. Install it.
3. Set the JAVA_HOME environment variable.
4. Verify installation:
```
java -version
javac -version
```
